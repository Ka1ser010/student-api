# Student Management REST API

A REST API for managing student enrollment records at a swimming school,
created to meet a real need of the school and serve as a backend portfolio project.

## Stack (Phase 1)

- **FastAPI** — web framework
- **SQLAlchemy** — ORM (object-relational mapping)
- **SQLite** — local database (single file, no install required)
- **Pytest** — automated testing

## Getting started

```bash
# 1. Create and activate a virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the server
uvicorn app.main:app --reload
```

The API runs at `http://127.0.0.1:8000`. Interactive documentation
(Swagger, auto-generated by FastAPI) is available at
`http://127.0.0.1:8000/docs` — every endpoint can be tested directly
from the browser, no Postman required.

## Running the tests

```bash
pytest -v
```

## Data model

Each student record has: `full_name`, `email` (unique), `phone`
(optional), `level` (e.g. beginner/intermediate/advanced), and
`active` (boolean).

## Available endpoints

| Method | Route               | Description                          |
|--------|---------------------|---------------------------------------|
| POST   | `/students/`        | Create a new student                  |
| GET    | `/students/`         | List students (supports `skip`/`limit` pagination) |
| GET    | `/students/{id}`     | Retrieve a specific student           |
| PUT    | `/students/{id}`     | Update one or more fields             |
| DELETE | `/students/{id}`     | Remove a student                      |

## Project structure

```
app/
├── main.py           # initializes FastAPI and registers routes
├── database.py        # database connection (SQLite for now)
├── models.py           # tables (SQLAlchemy)
├── schemas.py           # input/output validation (Pydantic)
└── routers/
    └── students.py       # student CRUD routes
tests/
└── test_students.py       # automated CRUD tests
```
